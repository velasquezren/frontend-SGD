Coloca aquí los archivos de la fuente de marca "Bufalo" (formato `.woff2`
preferido) para activar `--font-accent`. Ver el bloque `@font-face` comentado
en `src/styles/_tokens.scss` — descomentarlo una vez agregados los archivos.

Esta fuente es decorativa (script) y está pensada solo para titulares de
marketing/impresos, nunca para texto de interfaz o cuerpo de contenido.
